# Chusov Group — сайт лаборатории (редизайн chemcatgroup.com)

Сайт «Группы эффективного катализа» (ИНЭОС РАН, рук. Денис Чусов).



## Структура

```
index.html                 — главная
publications.html          — все публикации (по годам, с графическими абстрактами)
research.html              — направления исследований
people.html                — состав группы (Personnel)
alumni.html                — выпускники
news.html                  — блог (все 66 постов)
media.html                 — пресса о группе
open-positions.html        — вакансии (аспирантура)
former-members.html        — архивные страницы бывших участников (без ссылок из меню,
                             как и на старом сайте)
<имя-фамилия>.html         — персональные страницы (36 шт.): фото, инфа, ссылки на
                             ORCID/Scholar/ИСТИНУ, статистика цитирований, список статей

css/style.css              — вся стилистика (правится руками)
assets/img/                — все изображения, скачанные со старого сайта и сжатые

_build/site_data.json      — весь контент сайта в структурированном виде
_build/pub_meta.json       — авторы + цитирования каждой статьи (Crossref/OpenAlex)
_build/people_pubs.json    — публикации и статистика по каждому человеку
_build/profiles.json       — проверенные внешние профили (правится руками)
_build/fetch_pub_meta.py   — обновить цитирования: python3 _build/fetch_pub_meta.py
_build/match_people.py     — пересчитать статистику людей после обновления
_build/fetch_colab.py      — подтянуть данные с colab.ws (метрики/интересы/ID людей,
                             цитирования, поиск новых статей). Ключ — в _build/colab_key.txt
_build/colab_ids.json      — slug → colab-id (автоопределяется, правится руками)
_build/colab_meta.json     — метрики/интересы/ID с colab.ws (наслаивается в build.py)
_build/colab_new_pubs.json — найденные новые статьи Чусова, которых нет на сайте
_build/build.py            — генератор: python3 _build/build.py пересобирает все
                             HTML-страницы
```

## Обновление цитирований и данных

```
python3 _build/fetch_colab.py      # данные с colab.ws (метрики людей, интересы, ID, новые статьи)
python3 _build/fetch_pub_meta.py   # цитирования из Crossref/OpenAlex
python3 _build/match_people.py     # пересчёт статистики по людям
python3 _build/build.py            # пересборка страниц
```

`fetch_colab.py` кэширует ответы в `_build/.colab_cache/`, так что повторный запуск
почти не тратит квоту (1000 запросов); `--force` игнорирует кэш. Данные colab.ws
**наслаиваются** поверх ручных (`profiles.json`/`site_data.json` не перезаписываются):
метрики «all works» показываются там, где нет ручных чисел Scholar; интересы и
недостающие ссылки Scopus/Scholar добавляются на страницы профилей.

### API-ключ colab.ws (секрет!)

Ключ лежит в `_build/colab_key.txt` (или переменной `COLAB_API_KEY`) и **в git не
попадает** — файл в `.gitignore`. Никогда не коммить ключ и не вставляй его в HTML/JS:
сайт статический, любой его JS публичен. Синхронизация — только билд-тайм.

## Как править

- **Тексты страниц и разметка** — в `_build/build.py` (шаблоны), затем
  `python3 _build/build.py`.
- **Новая публикация / новость / человек** — добавить запись в
  `_build/site_data.json` (формат виден по соседним записям), положить картинку в
  `assets/img/...`, пересобрать.
- **Стили** — `css/style.css`, пересборка не нужна.
- Можно и просто править готовые HTML-файлы руками — они самодостаточны.


## Дизайн

Ориентир — классические сайты сильных групп (Baran Lab и т.п.), осовремененные:
системный шрифт интерфейса (SF Pro / Segoe UI / Roboto) без веб-шрифтов, белый фон,
липкая тёмная шапка с блюром, один синий `#1568b8` для ссылок и кнопок, скругления
8px, тонкие рамки и деликатные ховеры. Липкая полоса годов на странице публикаций. Все тексты — дословно
со старого сайта (включая фирменные «Our scientific warriors» и «The Chemistry for
me»). Логотип-белка и рисованная схема с выхлопной трубой — материалы группы,
сохранены намеренно. Хостить можно на любом статическом хостинге
(GitHub Pages, Netlify и т.п.).
